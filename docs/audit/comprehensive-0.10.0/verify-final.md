## Interactions of the new required questions

- **First-time:** neither `leftover-not-converted` nor `missed-money-value-loss` is required there.
  An empty program-answer set gives 2,000, and extra annual answers are accepted.
- **Annual vs missed-year scope:**
  - `missed-money-value-loss` is not referenced by the Sistani annual program. Giving it anyway is
    accepted.
  - For Khamenei it is not a pack question, so giving it → INPUT_UNKNOWN_QUESTION (correct).
- **Order of stops:** period no plus leftover no → only `consult-period` is shown (the leftover is
  nested inside it). That is acceptable.
- **Empty sheet:** with leftover no it stops; with yes the total is 0. AS-9 is unchanged.
- **Unanswerable text-settled cases:** none produce a wrong figure. Over-stops (below) make some
  text-settled cases end at a stop.
