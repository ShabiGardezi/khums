# Fresh independent audit — scholar-review packs 0.8.0 (2026-11-23)

Read-only audit at the maintainer's request. No code, rule pack, role, permission, governance or
database was changed; nothing committed or deployed. Three independent reviewers (Sistani pack,
Khamenei pack, per-year answer isolation) each made their own pass before reading earlier reports;
the coordinator then reproduced every HIGH finding against the sealed 0.8.0 packs. Figures are
technical results of the provisional transcriptions, never religious answers.

## 3. Per-year answer isolation

Isolated in every layer: engine, core, API contract, review screens. No way was found for one
year's answers to reach another. Shared answers on a missed-year sheet, per-year answers on other
workflows and unknown period ids are refused; an unanswered year is refused, never filled; screens
key answers by period id and discard them whenever the sheet changes; a result is shown only for
the exact input it was calculated from. Six LOW hardening items (engine-only duplicate-period
check, `in`-based answer lookup if a question were ever named `constructor`, Zod silently dropping
a `__proto__` key, the API reporting `ANSWERS_SCOPE_MISMATCH` as `INPUT_INVALID`, core not rejecting
unknown `entries` keys for non-API callers, and no up-front notice of which year is unanswered).
