Status: **approved by the owner 2026-11-24** (decision 71 records the device-storage decision; optional step 5 export/import is not to be implemented unless genuinely necessary). Based on a read-only review of the code on 2026-11-24.

| Area        | Implemented today                                                                                                                                                                                                                                                                                                                                         |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flow        | `/start` → Marja → assessment type → summary → details → review → results (`onboarding-flow.tsx`). ## 3. Owner decision (approved 2026-11-24, ARCHITECTURE §11 #71)

**Saving entries on the device.** Decision 27 says financial entries are held only in page memory
(never in browser storage). Reopening and editing a saved year (your item 4) requires storing the
entries and answers in this browser's `localStorage`. Proposal: allowed **only when the person
chooses "Save"**, stored only on this device, never sent, with the existing warning that anyone
using this browser can see them, and "delete one / delete all" always available. This supersedes
decision 27 for saved calculations only; unsaved work stays in memory as today.

## 5. Risks

- Storing entries on a shared device (mitigated by opt-in save, the warning and delete).
- Until scholars verify rules, the public calculator shows no figures; that is correct behaviour.
- A pack version change after saving: the reopened calculation is always recalculated with the
  current verified pack, never shown as current with old rules.
